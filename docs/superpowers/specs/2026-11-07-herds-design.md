# 远景 / 洲视图：按丰度散布的生物群（子项目 4/5）设计

> 2026-11-07 · 细节打磨系列：1 智能倍速 ✓ → 2 板块漂移插值 ✓（待迭代）→ 3 物种库扩充 ✓ → **4 远景 / 洲视图** → 5 近地视图

## 问题

- 远景（相机高度 ≥ 1.2 地球半径，含默认视角 2.4）地球上没有任何生物模型，只有化石点。
- 洲视图（< 1.2）全球最多 6 个模型（`pickCreatureSites`），每物种至少一个；丰度等级（`abundanceTier`）没有参与，"一片区域一个"。
- 地球上的模型只播 Idle；`BehaviorSystem`（idle / wander / eat）没有接入；没有睡觉、成群、追逐。
- 每个模型是一个带关节层级的 Rig（十几到几十个 mesh + 描线），无法直接放大到上千个。
- 数据规模：化石点 6,621 个（单物种最多 400），GBIF 现代分布点 7,505 个。

## 目标

- 远景能看到"有生命的全貌"：微缩模型 + 简单待机动作，散布密度按丰度数量级区分。
- 洲视图：植物更茂密，动物有漫游、进食、睡觉、成群、追逐 / 逃跑。
- 本机（Apple Silicon Mac）60 fps；低性能模式数量减半。
- 科学规则不变：个体只出现在真实化石点 / 观测点附近；物种严格按生存范围显示；与海岸线同一参考系。

## 方案选择

采用**远近两档混合**：

- **实例档**：每物种把静止姿态烘焙成一个合并几何体，用 `InstancedMesh` 批量绘制，待机动作在顶点着色器中完成。用于远景和洲视图中未升档的个体。
- **完整档**：洲视图中离视野中心最近的 ≤ 150 个个体换成完整 Rig + 行为状态机（原定 300，真机实测 300 只 49.5 fps，2026-11-07 调为 150）。

否决：
- 逐部件实例化 + CPU 关节矩阵（所有个体完整动画）：draw call 为部件数 × 物种数，每帧几万个矩阵，且要重写动画系统。
- 维持逐个 Rig 只放宽上限到 50–100：达不到按数量级区分密度的需求。

## 1. 数据

- 新增 `Species.diet: "carnivore" | "herbivore" | "omnivore" | "filter" | "detritivore" | "autotroph" | "unknown"`（科学属性，放物种记录，不放视觉资产）。
  - 105 种逐一填写，依据教科书级共识；无法确定的（如部分埃迪卡拉生物）写 `unknown`，不参与追逐。
  - `evidenceNote` 追加一句食性依据（例如"食性：[共识] 肉食，依据牙齿形态"）。不新增文献来源。
- 生境组复用 `habitatIds`：`marine / freshwater` → 水生；`terrestrial / forest / steppe / wetland` → 陆生；`coastal` 同时属于两组。
- 丰度等级沿用 `abundanceTier`：化石物种用 PBDB `occurrences`；全新世且使用 GBIF 现代分布的现生类群用 GBIF `records`（`source: "gbif"`）。

## 2. 散布（纯函数，`simulation/scatter.ts`）

- **每点个体数**（按丰度等级 1 / 2 / 3 / 4）：
  - 远景：1 / 2 / 4 / 8。
  - 洲视图（高度 < 1.2）：植物与固着生物（`locomotion: "none"`）×3，即 3 / 6 / 12 / 24；动物不变。
- **个体位置**：点位局部切平面上的偏移，种子 = 物种 id + 点下标 + 个体序号（`seededRandom`）。偏移半径 0.3°–1.2°，按丰度等级线性增大。偏移挂在点位上，随板块漂移整体移动。
- **海陆检查**：陆生个体落在海里或水生个体落在陆上时丢弃重抽，最多 3 次，仍不合格则不放；`coastal` 不检查。遮罩用当前切片的陆地遮罩（`landMask`），只在切片切换时重算。
- **全局上限**：只统计朝向相机的半球；远景 ≤ 2,000 个实例，低性能模式 ≤ 1,000。超出时按点位的固定哈希排序抽样，每个可见物种至少保留 1 个点；相机小幅转动时已选点保持稳定。
- **显示阈值**：高度 < 4 显示实例档（替代原来的 < 1.2）。
- **屏幕尺寸**：远景约 6–12 px（`globeModelPx` 按高度缩小），高度从 1.2 降到 0.6 时线性恢复到原来的 14–48 px。

## 3. 渲染

### 实例档

- `bakeSpecies`（纯 Three，可测试）：按"视觉资产 + 风格"构建 LOD1 Rig 的静止姿态，合并为一个几何体，附带每顶点的关节标签（头 / 颈 / 尾 / 高度等动作所需）。产出网点面与背面外扩轮廓两个几何体；折边线（`EdgesGeometry`）在实例档不绘制。
- 每个可见物种 2 个 `InstancedMesh`（面 + 轮廓），约 40 种 → 约 80 个 draw call。
- 材质：在 `createToneMaterial` 与轮廓材质的 `onBeforeCompile` 上加入实例化与待机动作；场景仍无灯光、网点自算光照。
- 实例属性：相位、动作类型、可见（升档后置 0）。
- 顶点着色器待机动作（uniform 为动画时钟，只随真实时间）：
  - 植物 / 固着生物：按顶点高度弯曲摇摆。
  - 陆生动物：轻微起伏，头颈顶点偶尔转动。
  - 游泳：左右摆尾；飞行：上下浮动。
- 屏幕尺寸与背面隐藏在着色器中计算（相机距离、视场角、视口高度 uniform）；背面实例缩为 0。CPU 只在点位移动（漂移形变比例变化）时更新实例矩阵，节流。
- 风格切换时重新烘焙（与模型按风格重建的规则一致）。
- 点击：射线检测得到 `instanceId` → 物种 → `selectSpecies`。

### 完整档

- 高度 < 1.2 时，离视野中心最近、屏幕尺寸 ≥ 14 px 的个体升为完整 Rig：上限 150（低性能 75），滞回为上限的 1.1 倍（实测调整，见上）。只升动物；植物在实例档已有摇摆。
- 同物种 Rig 用对象池复用。升档个体在实例档中隐藏；完整 Rig 用 0.25 s 由小到大弹出，降档反向。
- 动画沿用 `applyClip`，状态来自行为系统（§4）。

### 代码组织

- 新增 `scene/Living/Herds/`：`bakeSpecies.ts`、`instancedHerd.ts`（材质与实例属性）、`Herds.tsx`（实例档）、`HerdAgents.tsx`（完整档）。
- 替换 `scene/Living/GlobeCreatures.tsx`；`pickCreatureSites` 退役，测试改为覆盖 `scatter`。
- dev 模式暴露 `window.__herds`（实例数、完整档数、追逐组数）供 e2e 读取。

## 4. 行为（`simulation/BehaviorSystem.ts` 扩展 + `simulation/herdSim.ts`）

- **单位**：地球上模型不是真实比例，行为距离用角度。家 = 个体的散布位置；漫游半径按运动方式：crawl 0.05°、walk 0.15°、swim 0.2°、fly 0.35°；速度 = 半径 / 6 s 量级。
- **状态**：`idle / wander / eat / sleep / chase / flee`。
- **睡觉**：非飞行动物待机结束时约 15% 概率入睡，持续 8–15 s，播 `sleep`。无昼夜节律。
- **成群**：植食 / 滤食物种，同一点位的个体共享漫游目标，各带固定偏移。
- **追逐 / 逃跑**：
  - 配对条件（双方都在完整档）：捕食者 `diet` 为 carnivore / omnivore；猎物为动物且 `diet ≠ unknown`；生境组相同；猎物体长为捕食者的 0.1–1.5 倍；角距离 < 1°。
  - 过程：捕食者 1.6 倍速朝猎物当前位置，猎物 1.4 倍速背向逃，持续 4–8 s；距离拉开或超时后双方转为 idle / eat。不表现捕获或死亡。
  - 同时最多 8 组；每个个体结束后冷却 20–40 s。
  - 动画复用 `move`，播放速率 ×1.8。
- **动画片段**：`AnimationClipName` 增加 `"sleep"`。
  - quadruped / theropod / sauropod / hominin / bird / pterosaur：趴下或蹲坐 + 慢呼吸。
  - fish / marineReptile / whale / cephalopod：悬停，慢摆动。
  - arthropod / trilobite / insect：静止，附肢偶尔动。
  - plant / tree / herb / sessile：不实现；`animationSet` 不得包含 `sleep`。
- **开关与节流**：设置"动画"关闭时全部静止 idle（`behaviorConfigFor(…, enabled)`）；更新频率沿用 `updateInterval`；行为只随真实时间，与模拟倍率无关；物种离开生存范围时其个体与配对立即清除。

## 5. 测试与验收

### 单元测试

- `scatter`：个体数符合丰度表（远景 / 洲视图）；同输入可复现；海陆检查；全局上限 2,000 / 1,000；每可见物种至少 1 点；相机小幅转动选点稳定。
- `bakeSpecies`：每个原型可烘焙；顶点数与原 Rig 一致；包围盒尺寸等于 `Rig.extent`。
- `herdSim`：配对规则各条件的正反例；`unknown` 不参与；并发上限与冷却；追逐必定在时限内结束且猎物不移除；植物 / 固着生物不移动不入睡；动画关闭时全部静止。
- 数据：105 种都有 `diet`，`evidenceNote` 含食性依据；`animationSet` 与原型已实现片段一致（含 `sleep`）。
- 不变式：新组件不改时间、不重置相机。

### e2e（arm64 后台）

- `e2e/herds.spec.ts`：默认视角实例数 > 0 且 ≤ 2,000；拉近到洲视图出现完整档且 ≤ 150；点击实例打开物种详情；跳到另一时代后个体集合切换。

### 性能（本机真机，非无头）

- 场景：远景 · 白垩纪（可见物种最多）；洲视图 · 北美 · 150 完整档且有追逐；智能倍速播放全程（含板块漂移）。
- 各测 30 s：平均 FPS ≥ 60，1% 低帧 ≥ 45。结果记入 `TASKS.md`。
