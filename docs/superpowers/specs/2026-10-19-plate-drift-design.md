# 板块漂移插值（子项目 2/5）设计

> 2026-10-19 · 细节打磨系列：1 智能倍速 ✓ → **2 板块漂移插值** → 3 物种库扩充 + 比例 → 4 远景/洲视图 → 5 近地视图

## 问题

40 个重建切片（显生宙 20 Ma 一片，前寒武纪 100–200 Ma 一片）在切片边界瞬切：大陆、化石点、事件标记、生物模型一起跳一下。

## 方案：相邻切片之间的逐顶点形变（方案 A）

数据生成时为每个切片的每个轮廓顶点求出它在"下一个更年轻重建年代"的位置；客户端在两个年代之间按比例沿大圆插值，大陆连续漂移。到达年轻端时换成年轻切片自己的轮廓（两者在该时刻几乎重合，差异只来自地体出现 / 消失与融合，不做额外淡入淡出）。

否决的方案 B（每顶点板块 ID + 四元数 slerp，任意年代连续）：需在客户端逐帧做多边形融合，海岸线清晰度与性能都更差。

### 切片时间范围改变

切片 i（年代 tᵢ Ma）覆盖 `(tᵢ₋₁, tᵢ]`：从 tᵢ 开始向 tᵢ₋₁ 形变（t₋₁ = 0：1 Ma 切片形变到现今位置，接到全新世底界 11.7 ka 后换成现代海岸线）。最老的 1800 Ma 切片覆盖 `(1600, 1800]`；更早仍为"无数据"。

形变比例 `f = (tᵢ − t) / (tᵢ − tᵢ₋₁)`，t 为当前年代（Ma），夹取到 [0, 1]。

## 数据

`scripts/fetch-paleogeography.mjs`：

- 轮廓文件（仍为 `ett-outlines/1`）新增可选字段 `nextMa: number` 与 `next: LonLat[][]`（与 `outlines` 逐环逐点对应）。
- 求法：顶点 `reconstruct_points?reverse`（tᵢ → 现今）→ `reconstruct_points`（现今 → tᵢ₋₁；tᵢ₋₁ = 0 时直接用现今坐标）。原始响应缓存在 `node_modules/.cache/gws/`。
- 无效目标沿环借用最近有效顶点的位移（绕"有效顶点起点→终点"的最小旋转轴旋转相同角度）；整个环都无效时保持不动。无效目标包括（实现中发现板块错配后补充）：
  1. 无法反算或正算（null）；
  2. 离下一切片的实际轮廓超过 3°（目标本应落在那条轮廓附近）；
  3. 位移与环上前后各 4 个邻居的位移中位数相差超过 max(3°, 中位数的一半)；
  4. 整段一起错配：形变后某条边比原来长出 8° 以上视为撕裂，在撕裂处把环切开，只保留最长的一段。
- 错配的成因：融合后的轮廓顶点落在板块 / 地体边界附近，反算时被分到错误的板块，20 Ma 内"跳"几十度（实测 100 Ma 切片有 29 个顶点位移 25–62°，形变到末端时陆地遮罩出现放射状条纹）。处理后显生宙切片里离下一切片轮廓超过 6° 的目标 ≤ 0.2%，撕裂边 0–2 条。
- 点（化石点 / 事件）：每个与物种 / 事件时间重叠的切片，同时保证 tᵢ 与 tᵢ₋₁ 两个年代都有古坐标（tᵢ₋₁ = 0 用现代坐标，不存）。

## 客户端

- `simulation/paleoMorph.ts`（纯函数）：
  - `morphFraction(slice, yearsAgo)`
  - `slerpLonLat(a, b, f)`：大圆插值，处理经度跨 ±180°。
  - `morphOutlines(outlines, next, f)`
  - `paleoFrame(slice, yearsAgo)` → `{ kind: "modern" } | { kind: "paleo", ma, nextMa, f }`，取代 `frameFor`。
  - `speciesSitesInFrame` / `eventPositionInFrame` 按 frame 插值：两端都有坐标时插值；只有一端时用该端；两端都没有时不显示。
- 渲染（每帧在 `useFrame` 里读 `useTimeStore.getState()`，不触发 React 重渲染）：
  - 海岸线：几何体缓冲区原地更新（每切片约 2,500 顶点）。
  - 陆地遮罩：形变中画 1024 宽的低分辨率遮罩，停止 250 ms 后补画全分辨率；换切片时直接画全分辨率。两张纹理通过材质 uniform 切换，不触发 React 渲染。（实测 SwiftShader 下每帧重绘 4096 宽遮罩时播放帧耗时 217 ms，改后 83 ms，暂停 33 ms。）
  - 化石点、事件标记、地球上的生物模型：位置每帧按 frame 计算。化石点的点击判定用当前位置。
- 相机定位动作（跳到事件 / 物种）用当前时刻的 frame。
- 场景说明（GeographyCaption）标题为"板块重建 · tᵢ → tᵢ₋₁ Ma"，说明中注明两个重建年代之间是沿大圆插值的近似过渡（顶栏已显示当前年代，不再重复）。

## 测试

- `paleoMorph.test.ts`：f 两端与单调；slerp 端点、单位球上、跨日界线走短弧；形变轮廓 f=0/1 等于两端；点插值的缺端规则。
- 数据测试：每个切片有 `next`，与 `outlines` 结构一致，`nextMa` 等于相邻年轻年代；点数据覆盖新时间范围所需的两个年代。
- 切片解析测试按新时间范围更新。
- e2e：播放中相邻两帧海岸线像素变化量连续（无大于阈值的跳变），并且在一个切片区间内海岸线确实在动。

## 不做

- 切片边界处的轮廓淡入淡出（实测差异明显时再加）。
- 化石点按各自化石年代旋转。
